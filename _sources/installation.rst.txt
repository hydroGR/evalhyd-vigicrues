Installation
============

Il est recommandé d'installer certaines dépendances au préalable :

.. code-block:: console
   :caption: Installer ``evalhyd`` avec `pip`

   $ pip install evalhyd-python

.. code-block:: console
   :caption: Installer ``libhydro`` avec `pip`

   $ pip install git+https://gitlab.com/vigicrues/hydro3/libhydro

Il est ensuite possible d'installer `evalhyd-vigicrues` et ses autres dépendances via `pip` :

.. code-block:: console
   :caption: Installer ``evalhyd-vigicrues`` avec `pip`

   $ pip install git+https://forge.inrae.fr/hydroGR/evalhyd/evalhyd-vigicrues
